# list-store

A small event-sourced store for an ordered list of named items. State is `{ items: [{ id, name }] }` and is treated as immutable: reducers in `src/reducers.js` return a new state and never modify the one they were given, so any state object a caller holds (the initial state, a `prev` snapshot, a replay input) stays exactly as it was. `createStore(initial)` applies events through `dispatch(event)` and notifies `change` listeners with `{ event, prev, next }`; `replay(events, initial)` folds a list of events into a state without a store. Listeners are managed by the emitter in `src/emitter.js`: `on` returns an unsubscribe function, `once` fires a listener a single time, and adding or removing listeners while an emit is in progress must not cause any other listener to be skipped or called twice for that emit.
