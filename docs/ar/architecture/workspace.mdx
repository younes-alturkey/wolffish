# دماغ وكيلك على القرص

كل ما يعرفه وولفيش ويتذكره ويستطيع فعله يعيش في `~/.wolffish/workspace/`. هذا هو دماغ وكيلك على القرص — قابل للقراءة، وقابل للتحرير، وقابل لإدارة الإصدار بـ git.

## بنية المجلد

```
~/.wolffish/workspace/
├── brain/
│   ├── identity/
│   │   ├── soul.md                    # شخصية الوكيل
│   │   ├── user.md                    # ملف المستخدم
│   │   ├── workflow.md                # عقد القائد في وضع سير العمل
│   │   └── workflow-agent.md          # العقد المسلَّم لكل وكيل يُطلَق
│   ├── prefrontal/
│   │   ├── agents.core.md             # عقد التشغيل (مملوك لوولفيش)
│   │   ├── agents.md                  # إجراءاتك + تجاوزاتك (لا يُستبدل أبدًا)
│   │   └── .debug/                    # لقطات المحث (تُدوَّر، يُحتفظ بأحدث 50)
│   ├── cerebellum/                    # القدرات
│   │   ├── shell/                     # أوامر الشل (SKILL.md + plugin/)
│   │   ├── filesystem/                # عمليات الملفات (SKILL.md + plugin/)
│   │   ├── git/                       # عمليات git (SKILL.md فقط)
│   │   └── introspect/                # الوعي الذاتي + استرجاع الذاكرة (SKILL.md + plugin/)
│   ├── hippocampus/
│   │   ├── episodes/YYYY-MM-DD.md     # سجلات المحادثة اليومية (موسومة بالمصدر)
│   │   ├── consolidated/YYYY-WNN.md   # ملخصات أسبوعية
│   │   └── knowledge/                 # حقائق طويلة المدى (ملفات موضوعية)
│   ├── motor/tasks/TASK-{id}.md       # سجلات تنفيذ المهام
│   ├── basalganglia/YYYY-MM-DD.md     # سجلات الملاحظات اليومية
│   ├── brainstem/
│   │   ├── heartbeat.md               # تعريفات جداول الأتمتة
│   │   └── run-history.md             # سجل دائم لتشغيلات الأتمتة
│   ├── corpus/YYYY-MM-DD.log.md       # سجلات الأحداث اليومية (تُحذف بعد 7 أيام)
│   ├── conversations/                 # سجل الدردشة (مفهرس رسالة برسالة)
│   ├── projects.json                  # مخزن المشاريع (ما تحرّره صفحة المشاريع)
│   ├── procedures.json                # مخزن الإجراءات المحفوظة
│   └── cortex.db                      # فهرس سجلات SQLite (قابل للتخلص)
├── files/, uploads/, screenshots/, speech/   # المخرجات (تُفهرس كبيانات وصفية)
├── logs/                              # سجلات التطبيق + الامتداد (يُفهرس آخرها)
├── usage/                             # دفتر استخدام منظّم (مُفهرس)
├── whatsapp/read-history.json         # مخزن واتساب الوارد (مُفهرس لكل محادثة)
└── config.json                        # تكوين التطبيق (لا يُفهرس أبدًا — يحوي أسرارًا)
```

## المبادئ الرئيسية

**الملفات هي الحقيقة، و`cortex.db` ذاكرة مخبأة.** تفهرس قاعدة بيانات SQLite كل ما سبق — الحلقات، والمعرفة، والمحادثات (كل رسالة وكل استدعاء أداة)، وتشغيلات المهام، والملاحظات، والاستخدام، والسجلات، والبيانات الوصفية للمخرجات — وهي قابلة للتخلص بالكامل: احذفها وسيُعيد وولفيش بناءها من الملفات المصدر. التشغيل العادي يحدّثها عبر فرق تزايدي على mtime/الحجم (~22 مللي ثانية)؛ ولا تحدث إعادة البناء الكاملة إلا عند ارتفاع رقم إصدار مخطط الفهرس (~1.3 ثانية لمساحة عمل بحجم 2GB)، وليس عند كل تشغيل. لا تحرّر `cortex.db` مباشرة أبدًا — حرّر الملفات المصدر بدلًا من ذلك.

**ملفات يومية بدل ملفات تنمو بلا توقف.** الحلقات والملاحظات وسجلات الأحداث مقسَّمة حسب اليوم (`YYYY-MM-DD.md`). هذا يبقي الملفات الفردية صغيرة، ويسهّل تصفحها، ويتيح لـ brainstem تنظيف السجلات القديمة تلقائيًا.

**القدرات مكتفية بذاتها.** كل مجلد تحت `brain/cerebellum/` هو قدرة كاملة. يمكنك حذف أي منها دون التأثير على النظام الأساسي. يمكنك إضافة قدرات جديدة بإسقاط مجلد.

## فحص مساحة العمل

يتضمن وولفيش عارض ملفات ومحرر Markdown مدمجَين — يمكنك تصفح وتعديل مساحة العمل بالكامل دون مغادرة التطبيق. لمعظم الحالات، هذا كل ما تحتاجه. يمكنك أيضًا فتح `~/.wolffish/workspace/` في أي محرر خارجي إذا فضّلت ذلك. بعض الأشياء المفيدة للفحص:

| ما تريد معرفته | أين تنظر |
|---|---|
| ما السياق الذي أُرسل إلى نموذج اللغة | `brain/prefrontal/.debug/` (أحدث 50 لقطة محث) |
| ما يتذكره الوكيل عن اليوم | `brain/hippocampus/episodes/YYYY-MM-DD.md` |
| ما الأدوات التي استُدعيت وماذا حدث | `brain/motor/tasks/TASK-*.md` |
| هل يتعلم الوكيل تفضيلاتك | `brain/basalganglia/YYYY-MM-DD.md` |
| هل نُفِّذت أتمتة ما فعلًا | `brain/brainstem/run-history.md` |
| كل حدث أُطلق (آخر 7 أيام) | `brain/corpus/YYYY-MM-DD.log.md` |

### رقاقات المجلّدات الملموسة

على الحافّة العليا من نصّ المحادثة شريطُ **رقاقات مجلّدات** — كلُّ مجلّدٍ غيّرت المحادثةُ فيه ملفّات، وكم. وكلُّ رقاقةٍ على نقرةٍ من الفتح على سطح مكتبك، وتجيب سؤالاً واحداً: *أين عمل هذا الدور؟*

ومنذ **الإصدار 1.0.309** ينطوي كلُّ مجلّدٍ ملموس **إلى مجلّد المشروع الذي يفتح شجرته**، والعدّاتُ تُجمع عبر كلّ ما تحته:

- في محادثةٍ **بلا مجلّد عملٍ محدَّد**، كانت كلُّ رقاقةٍ تُسمّى بـ**طرف المسار** الذي لمسه الدور — فـ`…/wolffish-app/.github/workflows/ci.yml` يُنتج رقاقةً تقرأ **`workflows`** — فكانت المجلّدات التي عملتَ فيها فعلاً غير مرئيّة.
- والأسوأ أنّ عملاً يمتدّ على **مشروعين مبنيَّين بالطريقة نفسها** كان يضع **رقاقتين اسمُ كلٍّ منهما `src`** على الشريط، فوق شيفرتين مختلفتين، دون ما يميّز إحداهما عن الأخرى. والآن تقرأ الرقاقاتُ `wolffish-app` و`wolffish-cloud`.
- والمسحُ يجري **بالحدّ الأقصى أولاً** — أوّل `src` أو `lib` أو `test` أو `docs` أو مجلّدٍ بنقطةٍ في المسار — بينما تُعبَر الحاوياتُ مثل `apps` مباشرةً، فيُحسَب سطحُ مكتب السحابة **`desktop`** لا `apps` عامّاً، وينطوي مجلّدُ `.github` في مشروعه بدل أن يطالب برقاقةٍ خاصّةٍ به.
- والمساراتُ **خارج** مجلّدات العمل تحتفظ برقاقةٍ خاصّةٍ بها، وملفٌّ غُيِّر مباشرةً في مجلّد العمل ما زال يُحسَبه.

## التحكم في الإصدار

يمكنك تنفيذ `git init` على مجلد مساحة العمل لإدارة إصدارات دماغ وكيلك. هذا يتيح لك تتبع تغييرات الشخصية، ومراجعة تطور الذاكرة، والتراجع عن تغييرات التكوين، ومشاركة إعدادات وكيلك مع الآخرين.

```bash
cd ~/.wolffish/workspace
git init
echo "brain/cortex.db" >> .gitignore
echo "brain/prefrontal/.debug/" >> .gitignore
echo "config.json" >> .gitignore
git add .
git commit -m "Initial brain state"
```
