# ما هي القدرة؟

القدرة هي مجلد مكتفٍ بذاته في `brain/cerebellum/` يمنح وولفيش مهارة جديدة. القدرات هي الطريقة التي يتعلم بها وولفيش كيف يقوم بأشياء — تنفيذ أوامر الشل، وقراءة الملفات، والتفاعل مع git، والبحث في الويب، وإرسال الرسائل.

## بنية مجلد القدرة

```
brain/cerebellum/my-capability/
├── SKILL.md              # مطلوب: واجهة YAML + تعليمات
└── plugin/               # اختياري: كود قابل للتنفيذ
    └── index.mjs         # نقطة دخول الإضافة
```

## كيف تُحمَّل القدرات

عند بدء التشغيل، يمسح `cerebellum.ts` مجلد `brain/cerebellum/` ولكل مجلد:

1. يقرأ واجهة YAML لـ SKILL.md ويحلّلها
2. يستخرج تعريفات الأدوات وأنماط الخطر وأنماط التأكيد والمشغّلات
3. إذا كان مجلد `plugin/` موجودًا، يستورد `plugin/index.mjs` ديناميكيًا
4. يستدعي `init(context)` على الإضافة، ممررًا `pluginDir` و`workspaceRoot`
5. يسجل الأدوات في سجل cerebellum — كل قدرة تصبح مرئية في فهرس القدرات، لكن مجموعة فرعية فقط من مخططات الأدوات تُشحن إلى النموذج (انظر أدناه)

## كيف تصل القدرات إلى النموذج

تسجيل قدرة ليس مثل إرسال أدواتها إلى النموذج. يفصل وولفيش بين **معرفة وجود أداة** و**حمل مخططها** — هذا ما يُبقي موجه النظام رشيقًا مهما ثبَّت.

### فهرس القدرات

كل موجه نظام يحتوي فهرس `<capabilities>`: سطر واحد لكل قدرة — الاسم، ووصف قصير (بسقف 90 حرفًا)، وعدد أدواتها، مع علامة `[loaded]` على تلك التي أدواتها قابلة للاستدعاء الآن. الفهرس كله يكلف ~800 رمز، وبعد تجاوز 60 قدرة يتقلص الباقي غير المُحمَّل إلى عدد مُجمَّع، فتبقى كلفة الموجه ثابتة مهما بلغ عدد القدرات المُثبَّتة. النموذج يعرف دائمًا ما هو موجود؛ لكنه لا يدفع ثمن مخططات لا يستخدمها.

### القدرات الأساسية — دائمة التحميل

مجموعة إقلاع تُشحن مخططات أدواتها الكاملة مع كل طلب (~31–49 أداة): `tool-discovery` و`introspect` و`filesystem` و`shell` و`ask` و`utilities` و`web-search` و`secrets` و`system`، وأدلّة `operating-manual` و`pdf-design` و`dataviz` و`web-design` (سطر مخطط واحد لكلٍّ منها — ومتونها لا تُحمَّل إلا عند النداء)، و[`video`](/ar/integrations/video-generation) (فطلب المعالجة يجب أن يبلغ الأداة دون قفزة اكتشاف)، بالإضافة إلى `workflow` (متاحة لقائد [سير العمل](/ar/configuration/workflow-mode) وحده — الوكلاء لا يرون أدواتها أبدًا) وقدرات القنوات (`telegram` و`whatsapp` و`electron`، و`phone` [للإشعارات](/ar/integrations/notifications)) أثناء الاتصال. هذه هي المفاتيح إلى كل شيء آخر — الاكتشاف، واسترجاع الذاكرة، والملفات، والرد — ويجب ألا تتطلب أبدًا قفزة اكتشاف.

### كل شيء آخر — قابل للاكتشاف عند الطلب

GitHub وGoogle وNotion والمتصفحات واستخدام الحاسوب وأدوات الوسائط والمستندات وكل خادم MCP تُحمَّل عند الحاجة:

- `tool_search(query)` — بحث بالمصطلحات في أسماء القدرات وأوصافها ومشغّلاتها وأسماء أدواتها. أفضل مطابقة تُحمَّل تلقائيًا وتصبح أدواتها قابلة للاستدعاء في **نفس الدور**.
- `tool_activate(capability)` — تحميل صريح بالاسم الدقيق، من الفهرس أو من نتيجة بحث.

التفعيل **محصور بالمحادثة**: كل محادثة تحتفظ بمجموعتها النشطة الخاصة، فتحميل `github` في تشغيلة نبض قلب لا يُبطل أبدًا ذاكرة موجه محادثة حية. تبقى 10 قدرات غير أساسية كحد أقصى محمَّلة لكل محادثة، مع طرد الأقل استخدامًا مؤخرًا — والطرد غير مرئي، لأن استدعاء أداة مطرودة يُعيد تفعيل قدرتها تلقائيًا ويُنفَّذ الاستدعاء بشكل طبيعي. نفس المجاملة تنطبق على أي أداة معروفة لكن غير محمَّلة تُستدعى مباشرة: تعمل ببساطة. فقط اسم أداة مجهول فعلًا يُعيد خطأ، وذلك الخطأ يُشير إلى `tool_search`.

لجعل قدرات إضافية دائمة التحميل، أضف أسماءها إلى `pinnedCapabilities` (مصفوفة نصوص) في `config.json` — لا توجد واجهة لذلك؛ عدِّل الملف يدويًا.

### المهارات النقية

المهارات النقية (بدون أدوات) تظهر في الفهرس كإدخالات `(guide)`. يعثر عليها `tool_search` بالاسم أو الوصف أو الكلمات المفتاحية المُشغِّلة، ويقرأ النموذج تعليماتها عند الطلب بـ `skill_read_source`. لم يعد هناك حقن لمتون المهارات في الموجه بتحفيز الكلمات المفتاحية — سطر الفهرس هو كل ما تكلفه المهارة حتى تُحتاج فعلًا.

## القدرات المضمَّنة

يأتي وولفيش بهذه القدرات في مساحة العمل الافتراضية:

| القدرة | النوع | الوصف |
|---|---|---|
| `tool-discovery` | إضافة | العثور على أي قدرة وتحميلها عند الطلب عبر `tool_search` / `tool_activate` |
| `shell` | إضافة | تنفيذ أوامر الشل عبر `shell_exec` |
| `filesystem` | إضافة | قراءة الملفات وكتابتها وتعديلها |
| `git` | مهارة نقية | عمليات git عبر أوامر الشل |
| `introspect` | إضافة | استرجاع الذاكرة والوعي الذاتي: البحث في كل ما يعرفه وولفيش، وقراءة المحادثات السابقة، وفحص الحالة والإنفاق |
| `utilities` | إضافة | `send_file` — تسليم الملفات إليك كمرفقات (مسار التسليم الوحيد) — و`show_path`، بطاقة موضع مجلد/ملف قابلة للفتح |
| `ask` | إضافة | يسألك سؤالًا أو أكثر من أسئلة الاختيار من متعدد على بطاقة واحدة وينتظر إجاباتك |
| `skills` | إضافة | إدارة قدرات وولفيش وتأليفها أثناء التشغيل |
| `projects` | إضافة | إنشاء [المشاريع](/ar/configuration/projects) وإدارتها — تعليمات دائمة وملفات تُطلِع كل محادثة بداخلها |
| `pdf-design` | إضافة | **دليل تصميم المستندات** الأساسي — يُحمَّل قبل تأليف أي PDF أو مستند منسَّق |
| `dataviz` | إضافة | **دليل تصوير البيانات** الأساسي — متى يُرسَم، وأيّ رسم يُختار، وبطاقات `.chart.json` التفاعلية |
| `web-design` | إضافة | **دليل تصميم الويب** الأساسي — يُحمَّل قبل كتابة سطر HTML واحدٍ لأي صفحة تفتحها في متصفّح |

## إضافة القدرات وإزالتها

يمكنك إضافة قدراتك الخاصة بطريقتين:

- **أفلتها على الإعدادات ← القدرات** — ملف `SKILL.md` واحد، أو مجلد، أو ملف `.zip`. يُتحقَّق من كل عنصر قبل كتابة أي شيء، ثم يُحمَّل في الحال. تظهر القدرات المستوردة بوسم **غير معروف** (فهي قدراتك لا قدرات مدمجة)، ويمكن إزالتها بأيقونة سلة المهملات التي تحذف مجلدها نظيفًا.
- **أنشئ المجلد يدويًا** تحت `brain/cerebellum/`، ثم انقر **إعادة المزامنة** في اللوحة (أو أعد تشغيل وولفيش) لتحميله.

انظر [إنشاء القدرات](/ar/capabilities/creating-capabilities) للشرح الكامل، والأشكال الثلاثة للاستيراد، والقواعد التي يجب أن تستوفيها القدرة القابلة للاستيراد.

### حين تعتمد صفحة إعدادات على قدرة

معظم صفحات الخدمات في الإعدادات واجهةٌ أمامية لقدرة — استعمال الحاسوب، والميمز، وتحويل الكلام إلى نصّ، وتحويل النصّ إلى كلام، وGitHub، وNotion، وBrave، و[توليد الفيديو](/ar/integrations/video-generation). أطفئ تلك القدرة (أو دعها تخفق في التحميل) وكانت الصفحة تجلس بأدوات تحكّمٍ لا تفعل شيئًا بصمت.

صارت كلّ لوحةٍ **تفحص نفسها** وتقول أيّ الثلاثة وقع — القدرة **مفقودة**، أو **مطفأة**، أو **أخفقت في التحميل** (مع عرض الخطأ نفسه حين يوجد) — وتعرض طريقًا مباشرًا إلى صفحة **القدرات**. وأدوات التحكّم تحتها تصير خاملةً ظاهرًا بدل أن تتظاهر بالعمل.
