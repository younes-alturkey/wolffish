# ما الذي يُنشأ

عند تشغيل وولفيش لأول مرة، يُنشئ مساحة العمل في `~/.wolffish/workspace/` وينسخ ملفات التكوين الافتراضية من القوالب المرفقة. إليك ما يُنشأ:

## مساحة العمل

```
~/.wolffish/workspace/
└── brain/
    ├── identity/
    │   ├── soul.md          # شخصية الوكيل
    │   └── user.md          # ملفك الشخصي
    ├── prefrontal/
    │   └── agents.md        # إجراءات الوكيل وقواعد الأدوات
    ├── cerebellum/          # القدرات (shell, filesystem, git, إلخ)
    ├── hippocampus/         # الذاكرة (الحلقات، المُدمَجة، المعرفة)
    ├── motor/tasks/         # سجلات تنفيذ المهام
    ├── basalganglia/        # سجلات الملاحظات
    ├── brainstem/           # تكوين العمليات الخلفية
    ├── corpus/              # سجلات الأحداث
    ├── conversations/       # سجل الدردشة
    └── config.json          # تكوين التطبيق
```

## خطوات الإعداد الأولي

منذ **الإصدار 1.0.289** صار الإعداد الأولي **سمةً ولغةً ثمّ المحادثة** — لا شيء غير ذلك.

1. **المظهر** — اختر سمةً ولغة.
2. **المحادثة.** تحطّ في المحادثة.
3. **ضبط المزوّد** — اضبط مزوّدًا واحدًا على الأقل قبل رسالتك الأولى: [DeepSeek](/ar/configuration/deepseek) (موصى به)، أو Anthropic، أو OpenAI، أو أيّ من الباقين — أو [Ollama](/ar/configuration/ollama) للاستدلال المحلي.

<Note>
  **لم يعد Ollama خطوة.** كان التشغيل الأول يسوقك من شاشة الترحيب إلى *ثبّت Ollama*، ومنها إلى *اختر نموذج Ollama* — صفحتان ملءَ الشاشة لا تحملان شيئاً من تنقّل التطبيق، فمن لم يُرد نموذجاً محلّيّاً ببساطة لم يكن له مذهب. وصار وولفيش يعامل Ollama بما هو: **مزوّدٌ اختياريّ واحد بين عدّة**. ولم تعد شاشة انتقاء النموذج موجودةً أصلاً؛ صارت **لوحة Ollama في الإعدادات ← النماذج**، حيث تقصدها حين تريدها حقًّا. والإقلاع نفسه **لا يسأل Ollama شيئاً** — لا استطلاع، ولا قائمة وسوم، ولا إعادة كتابةٍ صامتة لإعداداتك قبل أن تظهر النافذة.
</Note>

## ما يحدث في كل تشغيل

بعد التشغيل الأول، كل تشغيل لاحق يقوم بما يلي:

1. يقرأ `config.json` لإعدادات النموذج والمزود
2. يهيّئ وحدات الدماغ الخمس عشرة عبر ناقل الأحداث (corpus)
3. يفهرس ملفات Markdown في مساحة العمل ضمن `cortex.db` (SQLite FTS5)
4. يبدأ العمليات الخلفية (مراقب الملفات، مجدول cron)
5. يفحص صحة المزودين (Ollama، وواجهات السحابة إن كانت مُعدة)
